# STILL HERE. / & AGAIN.

Obra digital editorial sobre identidad, fragilidad, confrontación, discernimiento, responsabilidad y transformación.

La página inicial presenta las preguntas del recorrido. Los cuatro actos contienen dos capítulos cada uno, con relato, desenlace, interpretación contemporánea, contradicción, fuentes y pregunta de continuidad. Los personajes no se convierten en modelos universales de éxito.

## Plataforma

HTML, CSS y JavaScript nativos. Cinco documentos HTML, sin compilación, servicios remotos, formularios ni almacenamiento de datos personales. Las imágenes y las fuentes se sirven localmente.

## Criterios de mantenimiento

- Conservar la identidad visual oscura y editorial.
- Mantener el mismo índice, navegación, progreso y estructura de capítulos en los cuatro actos.
- Respetar teclado, movimiento reducido y pantallas táctiles.
- Mantener el contenido legible sin JavaScript.
- No recuperar el archivo independiente del manifiesto, sus enlaces ni las secciones de cierre eliminadas.
- Conservar las fuentes narrativas y las notas sobre procedencia de las imágenes.
- Guardar capturas e informes de pruebas fuera del código publicado.

## Contenido

I: Narciso / La Caída. II: Goliat / Sísifo. III: Ícaro / Atlas. IV: Prometeo / Jacob.
