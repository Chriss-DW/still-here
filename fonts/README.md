# Tipografías locales

Tres familias en subconjuntos Latin WOFF2, con caracteres españoles y puntuación editorial. El sitio no solicita fuentes a terceros. `font-display: swap` mantiene la lectura durante la carga.

- Playfair Display: títulos y voz literaria, normal y cursiva, pesos 400–900. Licencia: `playfairdisplay-OFL.txt`.
- Inter: texto de lectura, pesos 300–700. Licencia: `inter-OFL.txt`.
- JetBrains Mono: navegación y numeración, pesos 400–700. Licencia: `jetbrainsmono-OFL.txt`.

Distribuidas bajo SIL Open Font License 1.1. Los archivos y sus licencias se conservan juntos en esta carpeta.
